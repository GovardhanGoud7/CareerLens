CareerLens 🔍
CareerLens is a simple, browser-based resume analyzer that helps you review your resume and understand how well it fits a career or job role.
Built with plain HTML, CSS, and JavaScript — no installation or backend required.
✨ Features
Upload or paste your resume text
Analyze skills, keywords, and structure
Get quick feedback and improvement suggestions
Clean, responsive interface
Runs entirely in the browser
🛠️ Tech Stack
HTML5 – page structure
CSS3 – styling and layout
JavaScript (Vanilla) – analysis logic
📁 Project Structure
CareerLens/
├── index.html   # Main page
├── style.css    # Styles
├── app.js       # Resume analysis logic
└── README.md    # Project documentation
🚀 Getting Started
Clone the repository:
git clone https://github.com/GovardhanGoud7/CareerLens.git
Open the project folder:
cd CareerLens
Open index.html in your browser.
That's it — no build steps needed.
📖 How to Use
Open the app in your browser.
Add your resume content.
Click Analyze.
Review the results and improve your resume.
